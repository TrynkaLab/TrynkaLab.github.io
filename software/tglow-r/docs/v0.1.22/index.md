# Introduction

Welcome to the tglow-r wiki! `tglow-r` is an R package for downstream analysis of `tglow-pipeline` outputs, modelled after Seurat, with data structures and utilities tailored to high-content imaging (HCI) data.

Please see the following pages for more information:

5. [Feature transformations, scaling](feature-transformation-and-scaling.md)
6. [Dimension reduction, clustering and plots](dimensionality-reduction-and-clustering.md)
7. [Modelling on the feature space](modelling-and-residuals.md)
8. [Differential abundance with MiloR](differential-abundance-with-milo.md)
