# Guided example

::: warning Not yet updated for v0.2.0
The guided example and its test data have not been updated for v0.2.0 yet.
The v0.0.1-beta test data uses 1-indexed channels and parameter names that
v0.2.0 rejects, so it will not run as-is.

Until the updated example is available, you can:

- Follow the [v0.0.1-beta guided example](https://trynkalab.github.io/software/tglow-pipeline/v0.0.1-beta/guided-example) with a v0.0.1-beta install.
- Check your v0.2.0 installation with the stub run described under [Installation](installation.md).
- Start from the example manifests in [Manifests and configuration](manifests-and-configuration.md).
:::
